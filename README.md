# Motion Analysis MATLAB Scripts

## Overview
This repository contains MATLAB scripts for processing motion analysis data exported from Vicon Nexus, including EMG, trajectory, model outputs, and force plate signals.

The workflow is organized into five main sections:
1. **EMG MVC processing**
2. **Motion extraction**
3. **Gait analysis**
4. **Balance analysis**
5. **Sit-to-Stand (STS) analysis**

## General workflow
The first two steps are required before running any task-specific analysis:

1. **EMG MVC**
   - Process MVC trials
   - Generate reference values for EMG normalization

2. **Extract Motion**
   - Load exported motion data from Vicon Nexus
   - Extract and organize trajectories, model outputs, EMG, and force plate signals

After these two steps, one of the following task-specific analyses can be run:

3. **Gait**
   - Process gait trials
   - Extract gait-related parameters from normalized signals

4. **Balance**
   - Process balance trials
   - Extract force plate and EMG-based balance parameters

5. **Sit-to-Stand (STS)**
   - Process sit-to-stand trials
   - Detect key events and extract normalized biomechanical and EMG signals

## Notes
- Task-specific scripts depend on outputs generated by the **EMG MVC** and **Motion extraction** steps.
- Kinematic and kinetic variables are taken directly from Vicon Nexus / Plug-in Gait outputs when available.
- These scripts are intended for research use and may require custom MATLAB helper functions included in the project.

## Suggested order of use
1. Run MVC processing
2. Run motion extraction
3. Run one of the following:
   - gait analysis
   - balance analysis
   - sit-to-stand analysis
